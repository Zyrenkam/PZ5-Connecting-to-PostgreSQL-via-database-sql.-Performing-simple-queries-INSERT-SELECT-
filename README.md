**Тема:** Подключение к PostgreSQL через `database/sql`. Выполнение простых запросов (INSERT, SELECT)

## Окружение
- **ОС:** Windows 10/11 (PowerShell)
- **Go:** 1.21+
- **PostgreSQL:** 18.6

## Описание
Программа подключается к локальной базе данных PostgreSQL `todo`, настраивает пул соединений `*sql.DB`, вставляет несколько задач параметризованными `INSERT`-запросами (с `RETURNING id`) и выводит список задач через `SELECT`. Дополнительно реализованы: фильтрация по статусу `done`, поиск задачи по `id`, массовая вставка в транзакции.
